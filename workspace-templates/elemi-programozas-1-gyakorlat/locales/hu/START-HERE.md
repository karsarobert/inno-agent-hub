# START-HERE – Így kezdd a gyakorlást

Üdvözlünk ezen a Python-alapozó gyakorlótéren! Így indulj:

## 0. Python 3 elérhetősége
Győződj meg róla, hogy elérhető a Python 3. Írd be a munkaterület alatti
terminálba:

```
python --version
```

(Előfordul, hogy `python3` a neve: `python3 --version`.)

## 1. A munkaterület szabálya
- Minden fájlt a munkaterület **gyökerébe** hozunk létre (pl. `lecke1_1.py`).
- A programot a **munkaterület alatti terminálból** futtatjuk:
  ```
  python lecke1_1.py
  ```

## 2. Így haladjunk az 1. leckével
Az 1. lecke **kód + viselkedés-megfigyelés**: a programot megkapod készen, a
feladatod az, hogy futtasd és **megfigyeld** a viselkedését.

1. Nyisd meg az `lecke1_1_hello.py` fájlt a munkaterületen.
2. **Először ne írd át** – csak olvasd el és **jósold meg** a kimenetet.
3. Futtasd a terminálban:
   ```
   python lecke1_1_hello.py
   ```
4. Figyeld meg a kimenetet, és válaszolj arra:
   - Mi jelent meg, és miért épp az?
   - Mi lenne, ha `print` helyett `PRINT` lenne? (gondold át)

> Minden fájl futtatása előtt mondd meg az Inno-Agentnek, **mit vársz** a
> kimenettől. Így erősödik a kódolvasási készséged.

## 3. Ha elakadsz
Írd meg az Inno-Agentnek, mit próbáltál és mit vársz. A segítség lépcsőzetes:
kérdés → tipp → részleges váz → teljes megoldás (csak kérésre, próbálkozás után).
