# START-HERE – How to start practising

Welcome to this Python-basics practice space! Here is how to start:

## 0. Is Python 3 available?
Make sure Python 3 is available. Type into the terminal below the workspace:

```
python --version
```

(It may happen that it is called `python3`: `python3 --version`.)

## 1. The rule of this workspace
- We create every file at the **root** of the workspace (e.g. `lecke1_1.py`).
- We run the program from the **terminal below the workspace**:
  ```
  python lecke1_1.py
  ```

## 2. Working through lesson 1
Lesson 1 is **code + behaviour observation**: you receive the program
ready-made; your task is to run it and **observe** its behaviour.

1. Open the `lecke1_1_hello.py` file in the workspace.
2. **Do not rewrite it first** – only read it and **predict** the output.
3. Run it in the terminal:
   ```
   python lecke1_1_hello.py
   ```
4. Observe the output and answer:
   - What appeared, and why exactly that?
   - What would happen if it said `PRINT` instead of `print`? (think about it)

> Before running any file, tell the Inno Agent **what you expect** from the
> output. This is how your code-reading skill grows.

## 3. If you get stuck
Tell the Inno Agent what you tried and what you expect. Help is stepped:
question → hint → partial outline → full solution (only on request, after
trying).
