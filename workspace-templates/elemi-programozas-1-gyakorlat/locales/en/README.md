# Python Basics — Student Practice Workspace

This workspace is a student practice space for **lab session 01 (Python
basics)** of a beginner programming course. The goal is not to take over
finished solutions, but to develop **code reading, behaviour observation and
independent experimentation**.

## How to use this workspace
1. **Start here:** read the `START-HERE.md` file.
2. **Files:** we always create and run Python files at the **root** of the
   workspace (e.g. `hello.py`, `lecke1_1.py`).
3. **Running:** use the **terminal below the workspace** (`bash` panel), where
   you start the program e.g. with `python lecke1_1.py`.

## The four lessons at a glance

| Lesson | Topic | File(s) at the root |
|-------|------|----------------------|
| 1. | First steps & data types – **code + behaviour observation** | `lecke1_1_hello.py`, `lecke1_2_tipusok.py`, `lecke1_3_operatorok.py` |
| 2. | Printing & text formatting | `lecke2_formazas.py` |
| 3. | Variables & operators | `lecke3_valtozok.py` |
| 4. | Type conversion & reading input (`input`) | `lecke4_konverzio_input.py` |

## Way of working
- In **lesson 1** the code and its behaviour are given; your task is the
  **observation**: you run the file and write down what you see and why.
- In **lessons 2–4** you first observe ready-made code, then develop it further
  with a **small modification / completion**.
- Every file is at the root; running happens from the terminal below the
  workspace.
