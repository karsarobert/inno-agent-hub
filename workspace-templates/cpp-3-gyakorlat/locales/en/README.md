# C++ Practice 03 – Control Structures

This package is the practical continuation of the **CPP_03 – Control Structures** theory material.
Time frame: **3 × 45 minutes of practice**, excluding breaks.

The main goal is no longer only to modify finished programs. The student now **writes small C++ code fragments independently, step by step**, while the Inno tutor briefly explains the new structure, shows a small example when needed, and then steps back so the student can work.

The practice is not built around one large project. Short, separate programs are used to explore `if`, `if–else`, `else if`, `switch`, `while`, `do–while`, and `for`, followed by two small combined tasks that use several already known ideas together.

## Important division of work

**The student writes, edits, and saves the code, and the student also compiles and runs it.**
Inno explains the task and the new concept, may show a short analogous example when necessary, helps interpret errors, and then waits for the student’s own attempt.

The student can run a program in two ways:

- with the **RUN** button above the code editor;
- or from the terminal, for example:

```bash
g++ -std=c++20 -Wall -Wextra -Wpedantic G03_01_if.cpp -o G03_01_if
./G03_01_if
```

No directory change is needed to use the RUN button. When working in the terminal, always use the actual filename for the current task.

## Structure of the practice

### Block 1 – decisions

- G03_01: simple `if`
- G03_02: `if–else`
- G03_03: `else if` chain
- G03_04: `switch`

### Block 2 – loops

- G03_05: `while`
- G03_06: `do–while`
- G03_07: `for`

### Block 3 – small combinations and closing

- G03_08: `for` + `if` – counting even numbers
- G03_09: `for` + `if` + accumulation – sum of numbers divisible by 3
- final multiple-choice test
- final output-prediction test
- short learning summary and memory save

## What is not included?

- no homework;
- no large multi-part application;
- no custom functions, arrays, pointers, or classes;
- no expectation that the student writes a complete program from memory in an empty file;
- no automatic source-file correction by the agent.

At the end, Inno clearly states that **the required CPP_03 practice has ended**, confirms that there is no homework, and records the actual progress, level of support, and final-test result in learner memory if that feature is available in the environment. Only after that may Inno offer **one short optional extra practice task** (`G03_EXTRA_practice.cpp`). The extra task is not part of the required completion.
