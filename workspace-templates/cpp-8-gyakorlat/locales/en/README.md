# CPP_08 InnoAgent – v2 student package

Independent application practice for lesson 8, **3 × 45 minutes**.
HTML retains complete theory examples; these tasks use different data and operations.

## Start

1. Extract into a **new, empty working folder**.
2. Do not overwrite the old measurement-track folder: it has different content and progress.
3. Open in InnoAgent and say: **“Let's start C++ practice 8!”**
4. Write/save your code and run with RUN. Build one cpp file at a time.

| File | Task |
|---|---|
| G08_01_duration.cpp | Duration |
| G08_02_rectangle.cpp | Rectangle and const |
| G08_03_lamp.cpp | Lamp and private |
| G08_04_tank.cpp | Tank and validation |
| P08_library.cpp | Library project |

Every starter compiles; requested classes, headers and loops are not prefilled.
Inno explains an analogy solving another problem, then you apply the idea.
Checks use actual code and state, rather than accepting only “it ran”.

If RUN fails:

~~~bash
g++ -std=c++20 -Wall -Wextra -Wpedantic G08_01_duration.cpp -o G08_01 && ./G08_01
~~~

No homework or automatically announced next-class exam.
