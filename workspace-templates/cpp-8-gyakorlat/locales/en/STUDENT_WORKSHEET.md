# CPP_08 v2 – Student worksheet

3 × 45 minutes excluding breaks. Apply the HTML concepts to new problems.
Inno explains the goal and an analogy, then you write one concrete step.
Save → RUN → check actual state. Unchanged starter output is not a solution.

## Block 1

- G08_01_duration.cpp: store minutes; compute hours and remaining minutes.
- G08_02_rectangle.cpp: area, perimeter and const snapshot.
- G08_03_lamp.cpp: state computed from two members, private and copying.
- G08_04_tank.cpp: filling limited by capacity, draining by contents.

## Block 2 – P08_library.cpp

1. Identify a title and set total stock.
2. Compute available copies and create a const snapshot.
3. Borrow when enough copies are available.
4. Accept returns up to actually borrowed copies.
5. Six titles, listing and two summaries.
6. Compare changing a copy with changing the original.

Failure preserves state. Read counts from queries.
