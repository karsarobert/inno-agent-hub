## Getting started

1. Extract the ZIP into a new working folder.
2. Open that folder in Innoagent.
3. Say: **“Let's start C++ practice 7!”**
4. Write and save your code, then use the **RUN** button.

The source files are starters, not completed solutions. Compile one at a time;
do not compile all cpp files together because they contain separate main functions.

If a terminal is needed:
```bash
g++ -std=c++20 -Wall -Wextra -Wpedantic G07_01_structure.cpp -o G07_01
./G07_01
```

## How you will work

Before each new step, Inno explains the goal, shows an example solving a
different problem, and explains the key lines. You write your own application;
help is given gradually if needed. The project grows in a single file.
