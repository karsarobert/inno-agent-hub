# CPP_07 – Student worksheet

## What are we practicing?

Group the data of a measurement into a structure. Compare making a copy with
modifying the original through a pointer, then process an array of measurements
using custom functions. Unions and scope have their own short exercises.

## Workflow – 3 × 45 minutes

Inno explains the goal and a similar example. You then write your own solution.
Concentrate on the current part. Save, use RUN, and interpret the result together.
For compilation errors, share the first relevant diagnostic and the affected code.
Do not inspect output from an old executable after a failed compilation.

## Block 1

| File | Task |
|---|---|
| G07_01_structure.cpp | Types, members, initialization and copying |
| G07_02_copying.cpp | Passing a structure by value, returning it and using a pointer |
| G07_03_union.cpp | Integer or real alternatives in shared storage, with a flag |
| G07_04_scope.cpp | Inner blocks, shadowing, a global name and a loop variable |

The requested operations are not prewritten. Examples help you recall syntax,
but you implement the application yourself.

## Block 2

Process six measurements in P07_measurements.cpp:
1. Print one measurement including its date.
2. Print the complete dataset.
3. Count valid measurements.
4. Calculate the average of valid values.
5. Count valid measurements strictly above a threshold.
6. Modify an original record through a pointer.

A negative temperature can be valid. A separate flag determines whether a
record is included in calculations.

## Block 3

Twenty questions follow, one at a time: ten multiple-choice, five output-reading,
and five debugging questions. Answer the output questions before running the code.
At the end, you receive section scores and review topics based on actual mistakes.
There is no homework.
