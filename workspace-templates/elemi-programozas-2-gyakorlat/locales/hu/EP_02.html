Önálló próba 1 – melyik függvény indul előbb?

A belső hívás eredményét a külső hívás kapja meg. A két függvény külön-külön is értelmezhető.

Futás előtt: Mondd végig a hívások sorrendjét, és minden visszatérésnél nevezd meg az értéket.

PYTHON
def dupla(szam):
    return szam * 2


def nagyobb(elso, masodik):
    if elso >= masodik:
        return elso
    else:
        return masodik


print(dupla(nagyobb(4, 7)))

14
Magyarázat felfedése

A nagyobb(4, 7) 7-et ad vissza. Ez lesz a dupla argumentuma, amely 14-et ad vissza. A print ezt az egy eredményt írja ki.

Egy módosítás, egy megfigyelés

Változtasd meg. Az utolsó sort cseréld print(nagyobb(dupla(4), 7)) sorra.

Jósolj, ments, futtass. Előbb mondd el, mit vársz. A futás után keresd meg a változást magyarázó sort.

A kísérlet értelmezése

Most előbb a dupla(4) ad 8-at, majd a nagyobb(8, 7) választ 8-at. A kimenet 8; nem mindegy, hogyan kapcsoljuk össze a függvényeket.

Önálló próba 3 – új jogosultsági szabály

Egy külön ajándékhoz az alapváltozatban diáknak kell lenni és legalább 2000 Ft-ért rendelni. Ez nem módosítja a közös büfé 10%-os szabályát.

Futás előtt: Melyik próba különíti el legjobban az and és az or használatát?

PYTHON
def ajandek_jar_e(diak_e, osszeg):
    return diak_e and osszeg >= 2000


print(ajandek_jar_e(True, 1999))
print(ajandek_jar_e(True, 2000))
print(ajandek_jar_e(False, 2500))

Változtasd meg. Az új szabály: diáknak lenni VAGY legalább 2000 Ft-ért rendelni is elegendő. Egyetlen operátort változtass meg.
