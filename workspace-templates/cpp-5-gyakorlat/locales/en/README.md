## Getting started

1. This package is already prepared as a workspace — nothing to extract.
2. Open this folder in Innoagent.
3. Write in the chat: **“Let’s start C++ Practice 5!”**
4. You edit and save the code. Use the **RUN** button to compile and run it.

From the terminal, for example:

```bash
g++ -std=c++20 -Wall -Wextra -Wpedantic G05_01_first_function.cpp -o G05_01
./G05_01
```

## How the project is taught

The project is more complex, so Inno does **not leave you completely alone with the syntax**.
Before each P1–P7 step, Inno:

1. explains what you are building and why;
2. shows a short sample program with different names, based on `SAMPLE_CODE.md`;
3. explains the key lines of the sample at a high level;
4. then asks you to adapt the idea to `P05_measurement_data.cpp`;
5. gives progressively stronger hints if you get stuck.

Inno does not write the complete project solution for you.

## Midterm preparation

The third block contains **20 pre-written questions**:

- 10 multiple-choice questions from today’s theory;
- 5 output-prediction tasks;
- 5 debugging tasks.

Earlier topics also return in the code-understanding section: loops, arrays, pointers,
`const`, functions, and namespaces.

There is no homework.
