# CPP_05 – Student Worksheet

## Time frame

The practice is **3 × 45 minutes**.

- Block 1: fundamentals of your own functions and prototypes
- Block 2: Measurement Data Analyzer project
- Block 3: 20-question midterm preparation test

## Working method

You write, save, and run the code. Primarily use the **RUN** button above the editor.
From the terminal, for example:

```bash
g++ -std=c++20 -Wall -Wextra -Wpedantic G05_01_first_function.cpp -o G05_01
./G05_01
```

If compilation fails, send Inno the first meaningful compiler diagnostic. After a failed
compilation, do not judge your new code by running an old executable.

## Block 1

1. `G05_01_first_function.cpp` – first custom function; two different operations
2. `G05_02_parameters.cpp` – two parameters; area and perimeter
3. `G05_03_void.cpp` – functions with no return value
4. `G05_04_prototype.cpp` – prototype and position of the definition

The starter files intentionally do not contain finished function headers or `return`
statements. If you get stuck, Inno first helps with an explanation and a smaller example.

## Block 2 – Project

Open `P05_measurement_data.cpp` and follow steps P1–P7 in `PROJECT.md`.
During the project you keep developing **one file**. Before each new section, Inno shows
a short, similar sample program, then you apply the pattern to your own project.

The examples in `SAMPLE_CODE.md` are there to support you, but do not copy them unchanged:
they use a different problem and different names.

## Block 3 – Midterm preparation

Inno asks the 20 pre-written questions from `FINAL_TEST.md` one by one:

- T1: 10 multiple-choice theory questions from today’s material;
- T2: 10 code-understanding tasks that also revisit earlier C++ topics.

T2 contains both output prediction and debugging. The goal is not to teach new material,
but to show which topics you should review before the midterm in the next lesson.

There is no homework.
