# Gyakorlófeladatok — f(x) = x²

**9. évfolyam · matematika**

> Szükséges eszközök: milliméterpapír (vagy koordináta-rácsos lap), ceruza, vonalzó, radír. A feladatokat az elméleti jegyzet (theory.md) mellett oldd meg! A **megoldókulcs** a lap végén található — csak akkor nézd meg, ha már minden feladatot megoldottál!

---

## Alap szint (mindenkinek)

**1. Számolj fejben!** Írd le a számok négyzetét: 6², 9², 12², (−4)², (−7)², 0², 0,5².

**2. Töltsd ki az értéktáblázatot!**

| x | −3 | −2 | −1 | −0,5 | 0 | 0,5 | 1 | 2 | 3 |
|---|---|---|---|---|---|---|---|---|---|
| **f(x) = x²** | 9 | | | | | | | | |

**3. Ábrázolás:** Rajzold meg az f(x) = x² függvény grafikonját milliméterpapíron (x = −3 … 3 között)! Ellenőrizd magad: a (0; 0) pont a csúcspont, és a grafikon az y tengelyre szimmetrikus.

**4. Jellemzés:** A rajzod alapján írd le a függvény jellemzését: értelmezési tartomány, értékkészlet, csúcspont, szimmetria, monotonitás, szélsőérték!

**5. Rajta van-e a grafikonon?** Döntsd el, és *indokold is* a válaszodat (helyettesítéssel!):
a) (4; 16)　b) (−4; 16)　c) (5; 10)　d) (0; 0)

**6. Ismétlő feladat (korábbi anyag):**
a) Számítsd ki: 11², 13², (−6)²!
b) Ábrázold az f(x) = 2x − 1 lineáris függvényt! Miben más a grafikonja, mint a paraboláé?

---

## Fejlesztő szint

**1. Finomítás:** Ábrázold az f(x) = x² függvényt **0,5-ös lépésközzel** (x = −2 … 2, azaz x = −2; −1,5; −1; −0,5; 0; 0,5; 1; 1,5; 2)! Mit tapasztalsz az előző rajzodhoz képest?

**2. Leolvasás a grafikonról:** Rajzold be a megfelelő vízszintes egyeneseket, és olvasd le:
a) Mely x értékekre igaz, hogy x² = 4?
b) Mely x értékekre igaz, hogy x² = 1?
c) Mely x értékekre igaz, hogy x² < 4? (A választ rajzzal indokold!)

**3. Metszéspont:** Rajzold be ugyanabba a koordináta-rendszerbe az y = x egyenest is! Mely pontokban metszi a parabola? *Következtetés:* mely x értékekre igaz, hogy x² = x?

**4. Négyzet és függvény:** a) Egy négyzet oldala 7 cm. Mekkora a területe? b) Mekkora annak a négyzetnek az oldala, amelynek területe 64 cm²? c) Fogalmazd meg, hogyan kapcsolódik ez a két feladat az f(x) = x² függvényhez!

**5. Szimmetria a függvény segítségével:** Miért igaz, hogy f(−2) = f(2)? Írd fel általánosan is: f(−x) = ? — majd igazold egy tetszőlegesen választott számmal! (Az ilyen függvényeket **páros függvénynek** nevezzük.)

**6. Ismétlő feladat (korábbi anyag):** Egy derékszögű háromszög két befogója 6 cm és 8 cm. Mekkora az átfogó? *(Segítség: Pitagorasz-tétel.)*

---

## Bővítő szint

**1. „Tükörkép":** Vizsgáld meg a g(x) = −x² függvényt: készíts értéktáblázatot (x = −3 … 3), ábrázold, és jellemezd! Mit tudsz mondani a grafikonjáról az f(x) = x² grafikonjához képest?

**2. „Eltolás":** Ábrázold az h(x) = x² + 1 függvényt ugyanabban a koordináta-rendszerben, mint az f(x) = x²-t! Mi változott és mi nem a jellemzésben? (Hol van a csúcspont? Mi lett az értékkészlet?)

**3. Szöveges feladat (labda):** Egy labdát függőlegesen feldobunk. A magassága t másodperc elteltével körülbelül h(t) = 10t − 5t² méter. Készíts értéktáblázatot (t = 0; 0,5; 1; 1,5; 2), ábrázold, és olvasd le: mikor van a labda a **legmagasabban**, és milyen magasan? Mikor ér vissza a földre (h = 0)?

**4. Összehasonlítás:** Töltsd ki az alábbi táblázatot, és fogalmazd meg a tapasztalatot: mikor nagyobb az x², mint a 2x, mikor kisebb, és mikor egyenlőek?

| x | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| **x²** | | | | | |
| **2x** | | | | | |

**5. Ismétlő feladat (korábbi anyag):** Melyik a nagyobb: 15² vagy 2¹⁵? Számolás nélkül is meg tudod becsülni — de számolj, és indokold is!

## Megoldókulcs

> ⚠️ **Csak a feladatok megoldása után nézd meg!** Ha egy feladatnál eltérés van, keresd meg, hol hibáztál — ne csak átmásold a megoldást!

### Alap szint
**1.** 36; 81; 144; 16; 49; 0; 0,25

**2.** 9; 4; 1; 0,25; 0; 0,25; 1; 4; 9

**3.** A pontok: (−3; 9), (−2; 4), (−1; 1), (0; 0), (1; 1), (2; 4), (3; 9); ezeket sima görbével kötjük össze. (Lásd theory.md 3. része.)

**4.** ÉT: ℝ; ÉK: [0; ∞); csúcspont: (0; 0); szimmetria: az y tengelyre; x < 0-nál csökkenő, x > 0-nál növekvő; minimum: 0, helye x = 0.

**5.** a) f(4) = 16 ✓ rajta van; b) f(−4) = 16 ✓ rajta van; c) f(5) = 25 ≠ 10 ✗ nincs rajta; d) f(0) = 0 ✓ rajta van.

**6.** a) 121; 169; 36. b) Az f(x) = 2x − 1 grafikonja *egyenes* (a (0; −1) és (1; 1) pontokon át), a parabola viszont görbe, és nincs rajta „törés".

### Fejlesztő szint
**1.** A fél egységenkénti pontok (0,25; 1; 2,25; 4 stb.) miatt a görbe **sima, kanyargó** lesz — látszik, hogy nem egyenes, és a csúcspontnál nincs törés (nem V alak).

**2.** a) x = −2 vagy x = 2 (az y = 4 egyenes metszéspontjai); b) x = −1 vagy x = 1; c) a (−2; 2) nyílt intervallum: −2 < x < 2 (ott van a parabola az y = 4 egyenes alatt).

**3.** Az y = x egyenes a parabolát a (0; 0) és az (1; 1) pontban metszi → x² = x pontosan akkor, ha x = 0 vagy x = 1. (Ellenőrzés: 0² = 0, 1² = 1.)

**4.** a) 7² = 49 cm²; b) 8 cm (mert 8² = 64); c) a terület az oldal négyzetfüggvénye: T(a) = a², és a területből az oldal „visszakeresése" pontosan az, amit a grafikonról való leolvasással csinálunk.

**5.** f(−2) = (−2)² = 4 = f(2). Általában: **f(−x) = f(x)**, mert (−x)² = x². Pl. x = 5: f(−5) = 25 = f(5). A függvény páros.

**6.** c² = 6² + 8² = 36 + 64 = 100 → c = 10 cm.

### Bővítő szint
**1.** A g(x) = −x² grafikonja az f(x) = x² grafikonjának **tükrözése az x tengelyre**: a parabola lefelé nyílik, csúcspontja (0; 0), ÉK: (−∞; 0], szimmetria az y tengelyre, és most **maximuma** van (a 0, az x = 0 helyen).

**2.** A h(x) = x² + 1 grafikonja az f(x) = x² **felfelé tolása 1 egységgel**: csúcspont (0; 1), ÉK: [1; ∞). A szimmetria és a monotonitás nem változik, a minimum értéke viszont 1 lesz.

**3.** Értéktáblázat: t = 0 → 0; 0,5 → 3,75; 1 → 5; 1,5 → 3,75; 2 → 0. A labda **t = 1 s-nál** van a legmagasabban, **5 méteren**; t = 2 s-nál ér vissza a földre (h = 0).

**4.** x²: 0; 1; 4; 9; 16 — 2x: 0; 2; 4; 6; 8. A 0-nál egyenlőek (0 = 0), az 1-nél a 2x nagyobb (1 < 2), a 2-nél egyenlőek (4 = 4), 2 fölött az x² nagyobb.

**5.** 2¹⁵ = 32768, 15² = 225 → a **2¹⁵ a nagyobb** (a hatványozás gyorsabban „nő", mint a négyzetre emelés).
