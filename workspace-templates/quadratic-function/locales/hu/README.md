# Másodfokú függvény — tanulói

Ez a munkatér a másodfokú függvény (f(x) = x²) bevezető leckéjének vezetett feldolgozására való, 9. évfolyamon.

## Használat

1. Írd be a chatbe, hogy „Taníts meg!", vagy egyszerűen kezdj dolgozni.
2. Az asszisztens lépésről lépésre vezet: visszakérdezés → tanulási cél → elméleti jegyzet → gyakorlatok → önellenőrzés.
3. Nyugodtan kérj magyarázatot bármelyik lépésnél, vagy kérj további hasonló feladatot.
4. A megoldókulcs a gyakorlatok és az önellenőrzés lap végén van — csak a saját megoldásod után nézd meg.
