# Python alapok · 01. gyakorlat (EP_01)

Üdv a munkaterületen! Ez a **Programozás alapjai** kurzus első Python-gyakorlata
(EP_01). Itt írod, mented és futtatod az **első Python-programodat** — kétféle
szerkesztővel és kétféle terminállal dolgozva.

## Mi hol van ebben a munkaterületben?

| Fájl / mappa | Mi ez? |
|---|---|
| `EP_01.html` | A **lecke tananyaga** (böngészőben nyitható). Ebből olvasod a magyarázatokat és a büfés példát. |
| `tanulo_lap.md` | A **feladatlapod** — a gyakorlat feladatai szintekre bontva (1.1 – 3.3). |
| `python_gyakorlat/` | **A munkamappád**: ide kerül minden `.py` fájl, amivel dolgozol. |
| `tanari_lap.md` | A tanári lap (megoldásokkal). **Csak ellenőrzéshez** — diákként ne nyisd ki, dolgozz a feladatlap alapján! |

## Így indulj

1. Nyisd meg az `EP_01.html`-t a böngészőben, és olvasd el az első fejezetet.
2. Nyisd meg a `tanulo_lap.md`-t: ott van a munkakörnyezet-leírás és az első feladat.
3. A `python_gyakorlat` mappában dolgozol: a kódot a **Notepad++**-szal vagy az
   **inno-agent beépített szerkesztőjével** írod, és a terminálban futtatod:

```bash
cd python_gyakorlat
python3 hello.py
```

A munkamenet-menetrend minden feladatnál:

```
Szerkesztés → Ctrl+S (mentés) → terminál → python3 fájlnév.py
```

Jó munkát! A munkaterület agentje lépésről lépésre vezet, és csak annyi segítséget
ad, amennyit kérsz.
