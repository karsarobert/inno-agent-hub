# Deep Learning 2026 · Practice 7 · Innoagent + Colab · 1.0 EN

The agent tutors through conversation. Students edit and run code in Google Colab.
This is a workspace instruction package for the existing Innoagent application, not an application installer.
Read START-HERE.md before beginning.

| File | Purpose |
|---|---|
| agent.md | Required tutor behavior, Colab workflow, feedback and conclusion. |
| LESSON_INSTRUCTIONS.md | Goals, actions, evidence and acceptance criteria for 32 code cells. |
| PROGRAM_GUIDE.md | Concepts, code explanations and troubleshooting support. |
| PROGRESS.md | Empty internal progress template; optional when native memory is unavailable. |
| PTE_DL7_EXERCISES.ipynb | Revised student notebook with 15 independent coding cells. |
| DL_07_practice_EN.html | Offline reference with different-data examples and interactive illustrations. |
| CELL_MAP.json | Relationship between original cells and current step IDs. |

Workflow: open → explain one cell → student edits/runs in Colab → actual short evidence → feedback → next cell.
There is no local Innoagent Run-button workflow, terminal work, file-tree refresh or automatic Colab connection.

Independent code is required in R04–R06, R10, M03–M06, M09, A03–A05 and A07–A09.
Other cells are prepared but still require interpretation. Three closing reflection questions are asked one at a time.

Internet and access to Colab are needed. TensorFlow, NumPy, Pandas, scikit-learn and Matplotlib run there.
GPU is optional. The instructor can provide official NPZ files if dataset downloads fail;
the loading cells detect files uploaded to Colab’s working directory.
