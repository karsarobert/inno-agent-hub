03 · Split first, then fit the scaler

Training data updates the network. Validation helps monitor learning and select a suitable state. Keep final test data separate until the final evaluation.

Training

Updates weights and determines preprocessing parameters.

Validation

Supports monitoring and early stopping.

Test

Measures the finalized model. Do not choose settings from it.

These examples use 60% training, 20% validation and 20% test data. This is a teaching choice rather than a universal rule. Time-dependent or grouped samples may require time-aware or group-aware splitting.

Why scale?

Speed is measured in thousands while load is around one. Scaling puts feature columns on more comparable numerical ranges. MinMaxScaler learns a separate minimum and maximum for each column.

Scaled value = (value − training minimum) / (training maximum − training minimum)

Try one feature

The training minimum is 10 and its maximum is 30. These parameters are already fixed.

The training range maps to 0–1. A new value outside that range may become negative or greater than 1.

MethodOperationData
fit_transformLearn parameters and transform.Training inputs only.
transformApply the existing parameters.Validation, test and new inputs.
Data leakage: fitting preprocessing on all data lets test information influence model preparation. Split before fitting the scaler.

Dividing image pixels by 255 uses a known scale rather than a maximum estimated from all images. MinMaxScaler also handles constant columns; a manually written division formula needs explicit zero-denominator handling.

04 · Let the task determine the output

Choose output activation, target representation and loss together. Hidden layers learn features; the final layer must produce the kind of result the task requires.

TaskTargetOutputLossEvaluation
RegressionOne real numberOne linear valueMAE or MSEMAE and a baseline

A · Regression

05 · Energy consumption: prepare the data

Estimate a fictional machine’s one-hour energy use. Generate inputs and targets from a simple rule plus noise. This is a learning example rather than an engineering sizing model.

Run the cells in order within each example.
R1 · Imports, data generation and inspection
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import MinMaxScaler
from sklearn.metrics import mean_absolute_error

keras.utils.set_random_seed(17)
rng = np.random.default_rng(17)
sample_count = 1200
speed = rng.uniform(600, 2400, sample_count)
load = rng.uniform(0.1, 1.0, sample_count)
temperature = rng.uniform(10, 35, sample_count)

X = np.column_stack([speed, load, temperature]).astype("float32")
# Target: energy consumed over one hour, in kWh.
y = (0.8 + 0.0012 * speed + 2.0 * load**2
     + 0.025 * temperature + rng.normal(0, 0.12, sample_count)).astype("float32")

print("Input:", X.shape, "Target:", y.shape)
table = pd.DataFrame(X, columns=["speed", "load", "temperature"])
table["energy_kWh"] = y
print(table.head())

column_stack turns three equally long series into columns: X has shape 1200×3. The network receives only input/target pairs, not the formula that generated them.

R2 · Separate subsets and scaling
# 60% training data and a 40% temporary subset.
X_train, X_remaining, y_train, y_remaining = train_test_split(
    X, y, test_size=0.4, random_state=17
)
# Split the remainder in half: 20% validation and 20% final test.
X_val, X_test, y_val, y_test = train_test_split(
    X_remaining, y_remaining, test_size=0.5, random_state=17
)

scaler = MinMaxScaler()
X_train_s = scaler.fit_transform(X_train).astype("float32")
X_val_s = scaler.transform(X_val).astype("float32")
X_test_s = scaler.transform(X_test).astype("float32")

print("Training:", X_train_s.shape)
print("Validation:", X_val_s.shape)
print("Test:", X_test_s.shape)
After running

Subset shapes are (720, 3), (240, 3) and (240, 3). Only inputs are scaled; targets remain in kWh.

06 · Build and train the network

Three inputs feed hidden layers of 24 and 12 units, followed by one energy prediction. A linear output is not restricted to the interval 0–1.

R3 · Build and train the model
# Re-run this cell for a new experiment: create a fresh model.
model = keras.Sequential([
    keras.Input(shape=(X_train_s.shape[1],)),
    layers.Dense(24, activation="relu"),
    layers.Dense(12, activation="relu"),
    layers.Dense(1)

model.compile(optimizer="adam", loss="mae")
model.summary()

early_stop = keras.callbacks.EarlyStopping(

history = model.fit(

    validation_data=(X_val_s, y_val),
    epochs=100, batch_size=32,
    callbacks=[early_stop], verbose=1
)

A · Regression

07 · What do learning curves tell you?

history.history stores measurements per epoch. loss is measured on training data; val_loss uses validation data. Compare the same loss across two different subsets.

R4 · Actual learning curves
plt.figure(figsize=(8, 4))
plt.plot(history.history["loss"], label="Training MAE")
plt.plot(history.history["val_loss"], label="Validation MAE")
plt.xlabel("Epoch index (starting at 0)")
plt.ylabel("MAE [kWh]")
plt.title("Energy consumption – learning curves")
plt.legend()
plt.tight_layout()
plt.show()

Three illustrative learning situations

These are fixed illustrative curves, not measured outputs of the Python example.

Four important early-stopping settings

  • monitor="val_loss": follow validation loss.
  • min_delta=0.001: the minimum improvement that counts; its meaning depends on the loss scale.
  • patience=8: allow eight consecutive epochs without sufficient improvement.
  • restore_best_weights=True: restore the state selected by the improvement rule.
Loss and accuracy measure different things. Loss can change while predicted classes stay the same. Dropout can also make validation loss lower than training loss; that alone is not an error.

A · Regression

08 · Is the model better than a simple baseline?

MAE reports average absolute error, here in kWh. A value of 0.20 kWh means an average absolute difference of 0.20 kWh, not the same error on every sample.

MAE = average of |actual value − predicted value|
R5 · Final test, baseline and a new input
# Inspect the test set only after finalizing the configuration.
test_mae = model.evaluate(X_test_s, y_test, verbose=0)
prediction = model.predict(X_test_s, verbose=0).ravel()

# A natural MAE baseline always predicts the training target median.
baseline_prediction = np.full_like(y_test, np.median(y_train))
baseline_mae = mean_absolute_error(y_test, baseline_prediction)
print(f"Network MAE: {test_mae:.3f} kWh")
print(f"Constant baseline MAE: {baseline_mae:.3f} kWh")
print(pd.DataFrame({"actual": y_test[:5], "predicted": prediction[:5]}))

# Keep the same column order: speed, load, temperature.
new_sample = np.array([[1500, 0.65, 24]], dtype="float32")
new_sample_s = scaler.transform(new_sample)
new_prediction = model.predict(new_sample_s, verbose=0)[0, 0]
print(f"Predicted energy for the new operating condition: {new_prediction:.2f} kWh")

predict returns shape (sample_count, 1); ravel makes a one-dimensional series for a table. New inputs must use the same column order and the already fitted scaler.

After running

Compare network MAE with the constant median baseline. If the network is worse, inspect inputs, scaling and curves. Five displayed predictions do not replace evaluation of the entire test set.

B · Classification

09 · From image to vector: reshape

A grayscale image stores one intensity per pixel. A 6×6 image contains 36 numbers. Flattening passes them to a dense network in one vector: values are preserved while layout changes.

Find the same pixel in the vector

Select a pixel or vector element. Both highlights refer to the same value.

ShapeMeaning
(900, 6, 6)900 images, each with six rows and six columns.

In reshape(-1, 36), 36 is the size of one image vector. -1 asks NumPy to infer the sample count. The total element count must stay unchanged.

After flattening, a Dense layer is not given an explicit spatial-neighborhood structure. This exercise uses dense networks; convolutional models are another option for images.

For 0–255 images, float32 conversion and division by 255 produce values in 0–1. The following synthetic images already use that range, so do not divide them by 255 again.

B · Classification

10 · Three geometric patterns and their labels

Distinguish vertical lines, horizontal lines and crosses. Add noise to clean patterns. Integer labels are 0, 1 and 2; the model learns from the generated image/label pairs.

Run the cells in order within each example.
C1 · Generate and display images
import numpy as np
import matplotlib.pyplot as plt
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
from sklearn.model_selection import train_test_split
from sklearn.metrics import confusion_matrix, ConfusionMatrixDisplay

keras.utils.set_random_seed(23)
rng = np.random.default_rng(23)
class_names = ["Vertical", "Horizontal", "Cross"]

patterns = np.zeros((3, 6, 6), dtype="float32")
patterns[0, :, 2:4] = 1.0
patterns[1, 2:4, :] = 1.0
patterns[2] = np.maximum(patterns[0], patterns[1])

# 300 images per class: 900 samples in total.
y = np.repeat(np.arange(3), 300)
images = patterns[y] + rng.normal(0, 0.22, (900, 6, 6))
images = np.clip(images, 0, 1).astype("float32")

fig, axes = plt.subplots(1, 3, figsize=(7, 3))
for class_id, ax in enumerate(axes):
    ax.imshow(images[class_id * 300], cmap="gray", vmin=0, vmax=1)
    ax.set_title(class_names[class_id])
    ax.axis("off")
plt.tight_layout()
plt.show()
print("Images:", images.shape, "Labels:", y.shape)

clip limits noisy values to 0–1. patterns[y] selects the clean pattern for each label. The short loop displays the three example images.

C2 · Split, flatten and encode
X = images.reshape(-1, 36)
X_train, X_remaining, y_train, y_remaining = train_test_split(

X_val, X_test, y_val, y_test = train_test_split(

print("Input:", X_train.shape)
print("Integer labels:", y_train[:5])
print("One-hot labels:", y_train_oh[:5])
print("Label array shape:", y_train_oh.shape)

stratify helps preserve class proportions. One-hot encoding maps class 0 to [1,0,0], class 1 to [0,1,0] and class 2 to [0,0,1]. The position represents a category, not an ordering by size.

11 · Softmax, dropout and class selection

The network turns 36 pixel values into three scores. Softmax produces nonnegative values summing to 1. They can be interpreted as estimated class probabilities, but do not guarantee a correct decision.

early_stop = keras.callbacks.EarlyStopping(

history = model.fit(

fig, ax = plt.subplots(1, 2, figsize=(10, 4))

Dropout(0.15) randomly zeros some incoming activations during training. Different units can be affected in different batches; units are not permanently deleted. Dropout is inactive during predict and evaluate.

Three outputs, one selected class

C · Anomaly detection

13 · Why train a network on its own input?

During normal machine operation, six sensor readings are related. An autoencoder learns these usual relationships and attempts to reproduce all six values. The training target is therefore the input itself.

The middle two values are a learned compressed representation, not two manually selected sensors. The network must express the relationships between six features through these two values.

Input → reconstruction → per-sample error → threshold → normal/anomaly decision
0 = normal; 1 = anomaly. Train only on normal training samples. Labels select normal data and evaluate decisions; they are not the autoencoder’s fit targets.

A large error indicates an unusual input, not proof of a fault or fraud. New valid operating conditions may differ from training data, and some anomalies may reconstruct well.

C · Anomaly detection

14 · Sensor data and selecting normal samples

Generate six related sensor readings from two hidden operating factors plus measurement noise. Anomalies change some usual relationships. These are artificial, labelled demonstration data.

Run the cells in order within each example.
A1 · Create six sensor features
import numpy as np
import matplotlib.pyplot as plt
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import MinMaxScaler
from sklearn.metrics import classification_report, confusion_matrix
from sklearn.metrics import ConfusionMatrixDisplay

keras.utils.set_random_seed(31)
rng = np.random.default_rng(31)

def sensors(sample_count):
    u = rng.uniform(0, 1, sample_count)
    v = rng.uniform(0, 1, sample_count)
    signals = np.column_stack([
        u, v, 0.7*u + 0.3*v,
        0.2*u + 0.8*v, u*v, (u + v)/2
    ])
    return signals + rng.normal(0, 0.015, signals.shape)

normal = sensors(1500)
anomalies = sensors(150)
# Change the usual relationships between several sensors.
anomalies[:, 2] += 0.55
anomalies[:, 4] -= 0.40

X = np.vstack([normal, anomalies]).astype("float32")
y = np.concatenate([np.zeros(1500), np.ones(150)]).astype("int32")
label_values, label_counts = np.unique(y, return_counts=True)
print("Labels and counts:", dict(zip(label_values, label_counts)))
print("Input:", X.shape)
A2 · Split, select normal data and scale
X_train, X_remaining, y_train, y_remaining = train_test_split(
    X, y, test_size=0.4, random_state=31, stratify=y
)
X_val, X_test, y_val, y_test = train_test_split(
    X_remaining, y_remaining, test_size=0.5,
    random_state=31, stratify=y_remaining
)

# Explicit Boolean mask: label 0 means normal.
normal_train = X_train[y_train == 0]
normal_val = X_val[y_val == 0]

# Learn the scale of normal operation only.
scaler = MinMaxScaler()
normal_train_s = scaler.fit_transform(normal_train).astype("float32")
normal_val_s = scaler.transform(normal_val).astype("float32")
X_test_s = scaler.transform(X_test).astype("float32")

print("Normal training samples:", normal_train_s.shape)
print("Normal validation:", normal_val_s.shape)
print("Mixed test:", X_test_s.shape)

y_train == 0 produces a Boolean mask. Selecting rows with that mask retains normal inputs. We obtain 900 normal training samples, 300 normal validation samples and a mixed test set of 330 samples.

Directly casting labels to bool would assign True to label 1, the anomaly here. Always check label meaning and use an explicit comparison.
After running

Training uses only normal inputs. Both classes remain in the test so false alarms and missed anomalies can be measured.

Use the same normal array as input and target. This example has a linear reconstruction output, so it can reproduce values outside the normal training range too. The exercise notebook uses a different, bounded sigmoid reconstruction output; choose activation according to the data and purpose.

A4 · Normal validation reconstruction errors
val_reconstruction = autoencoder.predict(normal_val_s, verbose=0)
# Compute one error value per row.
val_errors = np.mean((normal_val_s - val_reconstruction)**2, axis=1)
print("Reconstruction shape:", val_reconstruction.shape)
print("Error array shape:", val_errors.shape)
print("First five normal validation errors:", val_errors[:5])

# Derive the threshold only from normal validation data.
threshold = np.quantile(val_errors, 0.97)
print(f"97th percentile: {threshold:.6f}")

What does axis=1 mean?

Squared differences have shape (300, 6). Each row contains six feature errors for one sample. Averaging along axis=1 produces 300 per-sample errors.

Three feature differencesSquared differencesSample MSE
0.1; −0.2; 0.00.01; 0.04; 0.00(0.01 + 0.04 + 0.00) / 3 ≈ 0.0167

The 97th percentile places approximately 97% of the normal validation errors below the selected boundary. It is a teaching threshold rule, not a distribution-free guarantee about future false alarms.

This small reference example reuses normal validation for early stopping and threshold selection. A stricter workflow can reserve a separate calibration set, as the exercise notebook does. Neither workflow uses final test data to choose the threshold.

C · Anomaly detection

16 · A threshold changes decisions

Flag an anomaly when reconstruction error exceeds the threshold. A smaller threshold causes more alerts: it may catch more real anomalies while increasing false alarms.

Twelve labelled samples: move the threshold

Precision

TP / (TP + FP)

What fraction of alerts were real? Eight real anomalies among ten alerts gives 80% precision.

Recall

TP / (TP + FN)

What fraction of actual anomalies were found? Finding sixteen of twenty gives 80% recall.

Accuracy

(TP + TN) / all samples

What fraction of all decisions were correct? It can mislead when anomalies are rare.

If only ten of 1000 samples are anomalous, always predicting normal gives 99% accuracy and 0% anomaly recall. Evaluate the rare class separately.
Try and explain

reconstructions = autoencoder.predict(X_test_s, verbose=0)
test_errors = np.mean((X_test_s - reconstructions)**2, axis=1)
y_pred = (test_errors > threshold).astype("int32")

print(classification_report(

After running

Overlapping error distributions explain mistakes. Normal histogram bars can be taller because there are more normal samples. Do not adjust the threshold using final test results.

Why is PCA not a required step?

PCA can project samples into two dimensions, but reconstruction error in the full feature space makes the alert decision. Proximity in a projection does not establish a correct decision. First understand error distributions and confusion counts.
