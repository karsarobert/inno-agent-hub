Step 1

One row is one wine sample

The CSV file becomes a table in memory. We do not need a full pandas course today; we only need to understand what the rows and columns mean.

A simplified row

fixed aciditypHdensityalcoholquality
7.43.510.99789.45

The real dataset has 11 measured input columns. Only a few are shown here.

Read the file

raw_data = pd.read_csv(DATA_FILE)

Input: a CSV file on disk.

Output: a DataFrame – a table we can work with in Python.

Not important today: the detailed syntax used to construct DATA_FILE. It is support code that helps the script find the CSV file.
Step 2

Separate what the model sees from what it must predict

This is the X/y split. It is one of the most important ideas in supervised learning.

X – features
11 inputs

Measured properties such as acidity, pH, density and alcohol. These are allowed to enter the network.

y – target
1 answer

quality is the known value the network learns to predict.

features = data.drop(columns=["quality"])
target = data["quality"]
Why remove quality from X? If the answer stayed among the input features, the model would be given the value it is supposed to predict.
Step 3

The data has three different jobs

We do not use every row for the same purpose.

Training
≈60%
Validation
≈20%
Test
≈20%

Training

Used to update network weights.

Validation

Used to check the current model during development.

Test

Kept untouched for the final evaluation.

Important: validation and test are not just “extra training rows”. They have different roles.
Step 4

Scaling: learn the rule from training data only

Columns use different units and numerical ranges. Scaling makes their numerical ranges more comparable.

Same sample, different representation

Before

fixed acidity: 7.4

density: 0.9978

alcohol: 9.4

After scaling

fixed acidity: 0.28

density: 0.57

alcohol: 0.15

Illustrative values. The Python program prints a real sample from the dataset.

Two different verbs

train_scaled = scaler.fit_transform(train_features)

validation_scaled = scaler.transform(validation_features)
test_scaled = scaler.transform(test_features)

fit learn min/max from training data.

transform apply the already learned rule.

Data leakage rule: learn preprocessing rules from training data; apply them to validation and test data without learning from those sets.

Dense: each neuron receives information from all outputs of the previous layer.
ReLU today: know why an activation is present and that it adds non-linearity. We are not deriving its mathematics in this exercise.
Step 6

compile() configures learning

It does not train the model. It tells Keras how training should work.

What error should become smaller?

loss = "mae"

Mean absolute error measures the average size of prediction errors.

How should weights be updated?

optimizer = Adam

Adam uses gradient information to update the network parameters.

What should we report?

metrics = ["mae"]

A metric is a value we want to see when evaluating the model.

model.compile(
    optimizer=keras.optimizers.Adam(learning_rate=0.003),
    loss="mae",
    metrics=["mae"],
)
Key sentence: after this code runs, the network is configured but its weights have not been trained on the wine data yet.
Step 7

fit() starts the actual learning

Training data, epochs, batches and validation finally meet in one call.

history = model.fit(
    train_scaled,
    train_target,
    validation_data=(validation_scaled, validation_target),
    epochs=40,
    batch_size=64,
    verbose=2,
)

Read it as a sentence

Train on these inputs and correct answers, check the model on this validation set, make up to 40 complete passes through the training set, and process training examples in groups of 64.

Epoch
1
complete pass
Batches inside this epoch

Batch 1: a group of training samples is processed, then a weight update can occur.

Do not confuse them: a batch is a smaller group inside an epoch. One epoch contains many batches.
Step 8

history tells the story of training

fit() returns a History object. The graph is simply a visual representation of values recorded across epochs.

training lossvalidation loss

What should you understand?

Lower MAE means smaller average absolute error.

The curves show how training and validation error changed over epochs.

history.history contains the recorded values.

Support code: the Matplotlib lines that draw this figure are not a learning objective today. Understand the graph, not every line that creates the graph.
