# Beadandók

Ide kerülhetnek a tanuló által leadásra kijelölt forrásfájlok és rövid leírások.

Javasolt elnevezés:

```text
<modul>-<feladat>-<datum>/
  main.cpp
  README.md
```

A `README.md` írja le röviden a feladatot, a fordítási parancsot, a tesztelt bemeneteket és azt, mit tanult belőle a szerző. A beadandó megosztásáról mindig a tanuló dönt.
