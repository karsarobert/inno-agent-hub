# Tanári referenciaábrák

Ezek valódi CPU-s ellenőrző futások képei, nem a hallgató eredményei.
A számozás a hat fő programra utal. A futások beállításai és mérési adatai
az egy szinttel feljebb található ELLENORZES.md dokumentumban szerepelnek.
Az 05-ös kép az enyhe, 0.001-es L2-büntetés futásából származik.
A hallgató a saját nezet mappájából nyissa meg az aktuális képeket.
