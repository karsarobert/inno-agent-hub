# Let's begin!

Open the extracted workspace in Innoagent and type:

> Let's start Deep Learning Lab 4!

Inno explains the lesson and asks you to run `environment_check.py`.
A successful check ends with:

> ENVIRONMENT OK – CPU computation and figure saving succeeded.

Before each new example, Inno explains what it calculates and shows the important
code. After the introduction, first run it without changes. Make later changes
one at a time, save before running and change only the setting under investigation.
This keeps other settings comparable.

## If you get stuck

- **Missing package or import error:** show your instructor the last error lines
  and the printed interpreter path. Do not start installing packages yourself.
- **Training is silent for a few seconds:** wait for its summary. Do not start
  overlapping runs. The initial import can also take time.
- **No new image appears:** refresh the View folder / file list and open the new
  subfolder printed at the end of the current run.
- **Old settings appear in output:** check that you saved and ran the correct file.
  Avoid accidentally comparing old images.
- **Syntax error:** send Inno the short error and nearby lines. Inno helps you
  locate the issue; you make the correction yourself.

Read axis labels and legends. “It did not improve” or “there is no clear difference”
can be a valid observation supported by your results.
