# C++ Practice 4 – Short Student Worksheet

## Getting started

Write this in the Inno conversation:

**Let's start C++ Practice 4!**

You modify the programs yourself. After saving, use the **RUN** button. If you get a compilation error, send Inno the first relevant error message.

Expect two steps in every file:

- **A:** the basic task for the new concept;
- **B:** a more independent application in the same file.

The starter files intentionally **do not contain the key solution lines**. You need to write the indexing expression, loop, condition, or pointer expression yourself. Inno first helps with an explanation and a hint; a complete solution is given only when it is genuinely necessary.

You do not need to predict the output before every task. Prediction is used only at a few pointer-related points where it helps you understand what the code does.

## Reminders – without giving away the solution

### Array

- Indexing starts at 0.
- An array with five elements has five valid indices.
- The last valid index can be determined from the array size; during the practice, you will express this yourself in C++.

### Pointer

Always think in this order:

1. What is the value?
2. Where is the value stored in memory?
3. What address does the pointer store?
4. How can the object at that address be accessed?

### Array and pointer

At the end of the practice, you will access the same array element in two different ways. Do not copy the exact C++ expression from here: build it from the previous tasks.

## If you get stuck

1. Explain what you are trying to achieve.
2. Send the modified 3–8 lines or the error message.
3. Inno gives a hint first; you type the correction yourself.

## End of the practice

After the 10 programming tasks, a prewritten 12-question final test follows: 6 multiple-choice questions, then 6 short C++ programs whose output you determine. The tutor guides the test one question at a time; do not read the test file in advance as a solution sheet.

If you progress especially quickly, you may receive one additional complex independent challenge. It is optional and not homework.
