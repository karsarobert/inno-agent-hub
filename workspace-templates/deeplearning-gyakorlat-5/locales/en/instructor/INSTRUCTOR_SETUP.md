# Instructor preparation

## Before installation

Place agent.md, the four G05 programs and helper modules in the workspace root,
with the data subfolder beside them. This ZIP is not an Innoagent installer or
application plugin. Assign the tutor instructions to the existing application
workspace in the usual way. Ensure the agent can read the guides in the current
folder and that no old instructions for another lesson remain active.

## Python environment

The supplied requirements.txt pins the versions actually tested on Linux x86-64
with Python 3.12. On other operating systems, select the appropriate TensorFlow
distribution for that platform. Do not automatically replace a working teaching
environment: first run the environment check and baseline programs.

If needed, as **instructor preparation**, run from the extracted folder:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python environment_check.py
```

Installation requires internet access and download time; do it before class,
not through the student tutor. Innoagent's Run must use the same prepared Python
interpreter. The check prints its exact path. The exercises do not download data
or require a GPU while running. Innoagent's model connection is a separate requirement.

cpu_environment.py disables GPUs before importing TensorFlow, limits CPU threads
and fixes the random seed. Training uses tf.data batches with limited background
threading so that several epochs work in modest environments. Input=target
pairing is visible in make_batches(...); the notebook's fit(x, x) idea is preserved.

## Pre-class trial

1. Environment check: full success, empty GPU list, check.png created.
2. G01 baseline and index 3. Refresh View and open the correct new image.
3. G02: 10 then 30 epochs, bottleneck 8. Measure total Run time on classroom machines.
4. G03: supplied reference loads without importing TensorFlow.
5. G04: thresholds 0.04, 0.025 and 0.06. Compare counts with REFERENCE_RESULTS.md.
6. Restore defaults in the classroom copy: G01/G03 index 0; G02 10 epochs,
   bottleneck 8; G04 threshold 0.04. These are the package defaults.

Never overwrite the supplied reference with one student's run. Data and reference
checksums are documented. If intentionally creating a new reference, update its
metadata, threshold reference results and guides together.

## Troubleshooting

- Only TensorFlow is missing: G01/G03/G04 can work; the full check reports PARTIAL
  ENVIRONMENT and exits nonzero. Record G02 as skipped for technical reasons.
- Missing NPZ: restore the complete data folder from the original ZIP.
- Old-looking image: refresh View and open the new folder printed by the latest run.
- Unexpected training result: restore settings, check package versions and the
  initial-weights identifier. Identical last digits are not required across machines.
- Duplicate agent response: distinguish repeated text within one response from
  the application rendering or delivering one message twice. The latter may
  require an application fix rather than a longer prompt.

## Pedagogical differences from the original notebook

The smaller dataset, split by source rows, supports short CPU runs. Normal-only
validation gives a clearer comparison with normal training error. The mixed
practice set is repeatedly inspected and used for threshold exploration, so
results are not claimed as independent final evaluation or clinical validation.
Independent G03/G04 programs and the fixed reference allow the lesson to continue
if training is unavailable; the agent states this before each such program.

## Short run folders and comparison

Each program has its own increasing counter. New runs do not overwrite previous
folders. result.json includes the exact save time. Extract into a clean workspace;
the program does not delete or rename old long-name folders. Check the new 10 → 30
sequence with comparison.png. The 30-epoch run still works alone, but cannot
produce a comparison without a matching earlier 10-epoch run. A bottleneck of 16
must not silently be compared against a previous run with bottleneck 8.

Both program output and agent instructions contain refresh reminders. Verify
actual agent compliance in a live trial using AGENT_TEST_CHECKLIST.md.

## English edition

Use a new English workspace and conversation. Do not combine the English scripts
with Hungarian data archives: their keys differ. The complete English package
includes its own matching archives, checksums and guides. Numeric values and
model behaviour are preserved. English sample figures were regenerated by running
the translated programs rather than carrying over Hungarian-labelled images.
