# C programozás bevezető — tanulói

Ez a munkatér a bevezető C programozási kurzus (BSc) vezetett feldolgozására való: algoritmikus gondolkodás, a C alapjai, gyakorlatok és önellenőrzés.

## Használat

1. Írd be a chatbe, hogy „Taníts meg!", vagy egyszerűen kezdj dolgozni.
2. Az asszisztens lépésről lépésre vezet: visszakérdezés → tanulási cél → elméleti jegyzet → gyakorlatok → önellenőrzés.
3. A példakódokat fordítsd le és futtasd (ajánlott: `gcc -std=c17 -Wall -Wextra -Wpedantic -o nevem nevem.c`).
4. Nyugodtan kérj magyarázatot bármelyik lépésnél, vagy kérj további hasonló feladatot.
5. A megoldókulcs a gyakorlatok és az önellenőrzés lap végén van — csak a saját megoldásod után nézd meg.
